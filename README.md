# Bannerlord-Weather-Bounds-Fix-NaN-Crash-Guard.
A lightweight Harmony compatibility patch for Mount &amp; Blade II: Bannerlord.  ## Some modded campaigns crash during campaign-map simulation with:  System.IndexOutOfRangeException DefaultMapWeatherModel.GetWeatherEventInPosition()  The crash can occur during mobile-party speed calculations, including the War Sails naval weather calculation path.
